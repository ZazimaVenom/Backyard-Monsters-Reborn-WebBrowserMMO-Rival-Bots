# 0.4 individual art generation record

All nine assets were generated individually and sequentially with the built-in image-generation tool, one call per file. No CLI/API fallback was used. The three new static designs use the supplied original as a design reference and an existing remake asset as the rendering reference. The six locomotion sheets use their matching remake static illustration to retain identity. Generated PNGs were copied unchanged to `public/assets/art/`, preserving their genuine alpha; no programmatic image editing was used.

Each new image is 1,254 × 1,254 RGBA. Each sheet contains four row-major frames in a 2 × 2 grid with 627 × 627 cells. Every image was visually reviewed; all six sheets passed an alpha-boundary check with zero solid (alpha ≥128) pixels crossing the cell dividers. These are one-view, four-pose cycles with runtime facing mirroring, not full directional walk/attack/death libraries. D.A.V.E.'s file retains the `walk` locomotion key but animates its existing remake's mechanical treads and chassis. Existing static designs were not overwritten.

Source IDs: Project X C11, Monster Lab 116, Catapult 51. The complete release set is 56 PNGs: 42 static images and fourteen four-pose sheets.
