BACKYARD MONSTERS REBORN - PRECOMPILED WINDOWS x64 CLIENT

1. Extract the entire client folder.
2. Open BackyardMonstersClient.exe (the game icon).
3. Type your server address in the toolbar and click Connect.

Default address: 127.0.0.1
You can change the server address at any time. Connect remembers it; Save adds an address to the saved list without connecting.

Keep the EXE, supporting DLLs, Assets folder and assets-manifest.json together. Everything is compiled. No build scripts are needed to play.

Example addresses:
Game at website root: 127.0.0.1
Supplied local PHP server: http://127.0.0.1:8080/
XAMPP game folder: http://127.0.0.1/Backyard-Monsters-Reborn/
Remote server: https://your-server.example/

Connect to an already running game server. Game artwork, sounds, scripts and styles load locally; login, multiplayer and saves use the selected server.

The .NET runtime is included. If Microsoft Edge WebView2 Runtime is missing, the client obtains Microsoft's runtime automatically when connecting; that download requires internet access.
