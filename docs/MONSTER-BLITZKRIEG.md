# Monster Blitzkrieg

In the home yard, select **Monster Blitzkrieg**. A healthy level-three Town Hall opens the first wave. From that first launch a six-day clock runs. The level-three-to-four original event remains available at later Hall levels in this remake. If an unfinished run expires, starting again begins at wave one. A completed run permanently keeps its reward.

The event sends the ten compositions in the supplied `MonsterBlitzkrieg.as`, in original order, from the northern approach. The seventh wave sends ten Ichi followed five combat seconds later by 50 Bolt. The fifth and tenth waves include Slimeattikus, with its offspring generated by real combat. Each wave has a three-second arrival countdown. The server saves the countdown, each pending group, positions, damage and the settlement under the keeper’s locked home row.

Your own towers, traps, defending champion and bunker fight automatically. Keep combined eligible building-health loss below 90 percent to clear the wave. A siren forfeits the attempt. Damage already dealt is applied to your surface yard once when the wave ends. **Repair base** restores the buildings immediately for free before the next attempt. Ranked invasions take priority and can temporarily interrupt event polling.

Completing wave ten unlocks Slimeattikus in the normal Hatchery and establishes level-one research. A retry, review or reload cannot pay twice. These defenses carry no competitive rank reward. See `MONSTER-EXPANSION.md` for the late-game Locker alternative.
