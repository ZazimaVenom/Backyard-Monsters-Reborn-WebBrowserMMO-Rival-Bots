# New art production

These are individually generated HD reinterpretations for this remake, made with the built-in image generator. Original source images were inspected as design references only. No original raster assets were copied into the shipped game. Terrain is opaque; each object/monster uses a transparent background. The current 0.6 collection has 70 PNG files: one terrain, 26 structures (24 home-building types and two territory structures), 15 normal monsters, three champions and twenty-five animation sheets (eighteen movement/emergence and seven dedicated attack sheets). The prompt entries below record the initial artwork; the versioned prompt records document later additions. Runtime movement and combat combine sprite transforms, particles and four-pose sheets. See the versioned prompt records for the later additions. This is not complete original directional animation or asset parity.

The twelve assets added in 0.3, their complete prompts, references and layout corrections are recorded in [ASSET-PROMPTS-V03.md](ASSET-PROMPTS-V03.md). Champions currently share one visual design across evolution levels; separate level-specific skins are not included.

## Animation sheet delivery

Each sheet is a native generated 1254 x 1254 RGBA PNG, divided into an exact 2 x 2 grid of 627 x 627 cells in row-major order. No programmatic resizing or image editing was applied. All four poses were visually inspected and solid alpha remains inside each cell. The renderer preserves alignment with a union crop across frames. Each file has true transparent pixels and opaque character pixels.

| File | Sequence | Playback | Scope |
| --- | --- | --- | --- |
| pokey-walk.png | Alternating feet and body rise | Loop | Four poses, one camera direction |
| teratorn-fly.png | Wings up, sideways, down, half-up | Loop | Four poses, one camera direction |
| wormzer-emerge.png | Head peek, half rise, full rise, settled coil | One shot | Four poses, one camera direction |
| gorgo-walk.png | Heavy alternating foreleg steps | Loop | Four poses, one camera direction |
| drull-walk.png | Alternating hind-foot steps and passing poses | Loop | Four poses, one camera direction |
| fomor-fly.png | Wing upstroke, spread, downstroke and recovery | Loop | Four poses, one camera direction |
| brain-walk.png | Alternating insect scuttle steps | Loop | Four poses, native screen-left facing |
| crabatron-walk.png | Heavy crab steps with pincer motion | Loop | Four poses, native screen-left facing |

These sheets contain distinct generated poses, not duplicated static frames. Fine contour and body differences remain between generated poses; they are short stylized cycles, not a claim of full original Flash animation fidelity. Other species and building animations currently use runtime transforms and effects.

## Art direction
Smooth HD hand-painted Japanese monster-tamer RPG aesthetic inspired by the warm detailed worlds of Digimon Dawn/Dusk, crisp outlines, teal shadows and warm highlights. Consistent three-quarter isometric view, whole isolated subject on true transparent alpha, no text or UI. Every asset is produced separately and visually inspected.
